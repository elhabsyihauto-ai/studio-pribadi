# Studio Pribadi by Suhu Digital

Aplikasi pribadi untuk membuat prompt video AI bagi tiga akun TikTok (Rio, Mia, Nara + kolaborasi), di Gemini Canvas.

- `pemanggil-studio-pribadi.html`: tempel di Gemini Canvas (memuat penanda alamat AI Gemini).
- `studio-pribadi.html`: aplikasinya (Bank Figur, lokasi, format per akun, Ide Konten, Lanjutkan Proyek).
- `figur/`: foto wajah resmi (`rio.jpg`; `mia.jpg` dan `nara.jpg` menyusul).

Mesin pembuat prompt diambil langsung dari Sugi Studio (`kreator.html` dan `serba-bisa.html` di repo Sugimation, cabang `main`), jadi setiap perbaikan Sugi otomatis ikut.
